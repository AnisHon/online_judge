# 愚蠢无比的OJ平台

这是一个愚蠢无比的OJ平台，源自24年无比愚蠢的我，脑袋空空拿到任务就是干。

- 没有 Special Judge，输出不一样就是不一样，别跟我解释
- 没有 Remote Judge，自己的题自己判
- 没有远程判题
- 不支持 OI 赛制
- 不支持标准 ACM/ICPC 赛制
- 不支持长简单的题目导入
- 不支持视频推推流
- 不支持流式文件预览
- 不支持聊天
- 不支持关注
- 不支持评论
- 不支持私信
- 可能有XSS注入问题
- 不支持真正意义上的比赛封榜
- 不支持分布式 Judge 调度
- 不支持优雅的 Judge 沙箱管理
- 不支持弹性扩容，因为我也不知道一个学校里的 OJ 为什么要弹性扩容
- 可能存在 CSRF，取决于当年的我到底在哪里偷懒了
- 可能存在越权，请不要对一个 2024 年写出来的权限系统抱有过高期待
- 可能存在死锁，我知道它在哪里，但我选择和它和平共处
- 没有分布式锁，因为当年的我已经引入了足够多的分布式玩具
- 没有数据库分布式锁，因为我不想为了修一个错误再制造三个错误
- 部分地方依赖最终一致性，“最终”到底是多久取决于 RabbitMQ 和上帝
- 某些异常恢复逻辑的设计思想是：如果不知道发生了什么，那就过一会儿再扫一遍
- 日志很多，但真正出问题的时候你需要 grep、耐心和一点运气
- 没有完善的可观测性，因为当年的我还不知道 Prometheus 和 Grafana 能让项目显得更像真的
- 没有完善的自动化测试，因为当年的我认为“我刚刚手点过了”也是一种测试
- 没有完善的压力测试，因为只要不知道 QPS 上限，就可以假装它没有上限
- 没有灾备，因为最可靠的灾备方案叫“希望服务器别坏”
- 没有高可用，因为只有一台服务器的时候不存在脑裂问题
- 没有 K8s，因为我不会，而且这个项目也不配

### 它居然能干什么

虽然上面说了这么多，但它确实是个 OJ：

- 用户注册、登录和权限管理
- 题目管理
- 测试数据管理
- 在线提交代码
- 编译和运行
- 判题
- 实时返回判题状态，我已经把我当年脑子一热的SSE干掉换成HTTP轮询了
- 比赛/活动相关功能
- 提交记录与统计
- 基础后台管理
- Docker 部署
- 以及一些我已经忘记为什么存在的功能

最可怕的是，他居然真的被人用过，因此我至今不敢直接把数据库删掉。

### 使用技术

- MYSQL，我希望有人能重构一下换到PSQL，这样测试用例就不用存到MINIO了。
- Redis，如果能引入PSQL，那我就把Redis删了
- MINIO，我希望我能买OSS而不是自己搭一个MINIO
- RabbitMQ，为了判题的队列，当年无比愚蠢的我引入了RabbitMQ
- SpringCloud Alibaba，我想逃离阿里系
- Docker/ Docker Compose，我不会K8S
- Vue 3 + TypeScript + Element Plus，当年的我不会写Vue，也不懂 Tailwind CSS
- Gateway

### 架构

本项目采用先进的： “我在博客上看到了这个，所以我要用”驱动架构。

基本原则包括：
- 服务我想拆就拆
- 能上中间件就上中间件
- 能异步绝不同步
- 能加缓存绝不直接查数据库
- 能配置中心绝不写配置文件
- 出问题以后再思考这些东西到底有没有必要

### 一致性
严格一致性？没有，部分流程采用最终一致性。

消息丢了怎么办？有兜底扫描。兜底扫描挂了怎么办？那你这能希望它不要挂。

RabbitMQ、数据库、Judge 和 SSE 之间如果出现某些极端时序问题，理论上可能产生一些非常有趣的状态。

如果你发现了BUG，欢迎提 Issue，我会关闭并且侮辱你。

如果你修了，欢迎提 PR，我会拒绝合并，然后侮辱你。

### 性能

不知道。没测过。

如果它慢：
- 可能是数据库。
- 可能是 Redis。
- 可能是 RabbitMQ。
- 可能是网络。
- 可能是 Judge。
- 可能是 JVM。
- 也可能单纯是代码写得烂。
- 还有可能是你没钱

这就是微服务的优势： 当系统变慢的时候，你拥有更多可以怀疑的对象。

### 安全性

请不要把它直接部署到互联网上然后期待它坚不可摧。

这是一个 OJ，而 OJ 的核心功能之一就是：
- 允许陌生人向你的服务器提交恶意代码，然后请求你运行它。
- 从产品设计上来说，这已经非常勇敢了。我尽可能做了一些隔离。
- 如果你准备用它承载重要业务：请重新考虑你的人生选择。

### 部署

Docker Compose，因为我希望：`docker compose up -d`

但是生活总是这样，你还需要处理数据库、Redis、RabbitMQ、MinIO、Nacos、网络、存储、证书、反向代理，以及一些只有部署以后才会出现的问题。
